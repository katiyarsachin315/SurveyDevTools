Survey Developer Tools

A collection of simple and useful web-based utility tools built to make survey programming, testing, and development faster and easier.

🚀 Overview

Survey Developer Tools brings commonly used survey programming utilities together in one place. Instead of creating small scripts or tools repeatedly, developers can use these utilities directly from a single application.

The tools are designed mainly for survey programmers and developers working with HTML, CSS, JavaScript, Decipher/Forsta, and related survey-development tasks.

🛠️ Available Tools
Lazy Looper – Quickly generate repeated blocks of code by replacing loop variables with sequential and custom values.
Resource Generator – Generate Decipher resource tags and attributes quickly.
Marker Tools – Simplify marker-related tasks and updates.
Variable Tools – Work with survey variables and related data.
Excel Utilities – Perform common Excel-related validation and processing tasks.
Text Utilities – Quickly format, modify, or transform text/code.
Other Survey Utilities – Additional small tools designed around common survey-development requirements.
